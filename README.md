# 🌍 Exploratory Data Analysis on Multiple Environmental Datasets

This repository presents a detailed **Exploratory Data Analysis (EDA)** on various environmental datasets, focusing on understanding pollution levels, weather parameters, and other ecological indicators across regions and timelines.

## 📌 Project Overview

With rising global concerns over environmental degradation, data-driven insights can guide policy and awareness. This project explores multiple environmental datasets to:
- Identify trends in air quality, temperature, humidity, and other factors.
- Detect anomalies and outliers in pollution data.
- Visualize how environmental variables change over time and across locations.

---

## 📁 Repository Structure

```
├── srishti.ipynb                    # Main Jupyter Notebook with full EDA workflow
├── README.md                        # Project documentation
```

---

## 🔍 Key Features

- 🌫️ **Pollution Analysis**: Examines levels of common pollutants (PM2.5, PM10, NO2, CO, etc.).
- 📈 **Trend Detection**: Uses line plots and moving averages to detect seasonal or long-term patterns.
- 📊 **Correlation Study**: Heatmaps and pairplots to understand relationships between variables.
- 📌 **Missing Value Handling**: Strategies for imputing or removing nulls in critical attributes.
- 🗺️ **Regional Comparisons**: Side-by-side analysis of environmental data from different cities or states.
- 📉 **Anomaly Detection**: Spots unusually high/low values which could indicate errors or environmental events.

---

## 🛠️ Technologies Used

- Python 3
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly (optional for interactive visuals)

---

## ▶️ How to Run

1. **Clone the Repository**
   ```bash
   git clone https://github.com/divyapandey1113/EDA-on-Multiple-Datasets-of-Environmental-Data-.git
   cd EDA-on-Multiple-Datasets-of-Environmental-Data-
   ```

2. **Install Required Libraries**
   ```bash
   pip install -r requirements.txt
   ```

3. **Launch the Notebook**
   ```bash
   jupyter notebook srishti.ipynb
   ```

- Box plots for identifying outliers
- Seasonal decomposition for trend + noise + seasonality
